# Nadia El Ferkane Blanc — thérapie familiale systémique

Site de présentation de Nadia El Ferkane Blanc, thérapeute familiale systémique, formatrice et intervenante en analyse des pratiques professionnelles. Consultations sur rendez-vous à La Ciotat et à Marseille.

Les textes, tarifs, diplômes, adresses et coordonnées reprennent le site public [therapie-familiale-systemique.com](https://www.therapie-familiale-systemique.com/). Le portrait et le dessin au trait (marque) sont les visuels fournis pour cette refonte.

## Pages

- Accueil
- Présentation
- Informations et tarifs
- Contact (téléphone et courriel, sans formulaire)
- Liens utiles

## Développement

```bash
npm install
npm run dev
```

```bash
npm run build
npm start
```

Pour les liens canoniques et le sitemap en production, définir `NEXT_PUBLIC_SITE_URL` (par exemple `https://www.therapie-familiale-systemique.com`). Sur Vercel, l’URL du déploiement est utilisée si cette variable est absente.
